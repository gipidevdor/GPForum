# Source Serif 4

Designed by Frank Grießhammer for Adobe. Copyright and SIL Open Font License
1.1 are preserved in `source-serif-4-LICENSE.txt`.

Locally served variable Roman and italic WOFF2 files, Latin and Latin extended.
The browser downloads only the styles and character ranges the page uses.
Weight and optical size are handled by the font; no remote font request is
made by the forum. The UI continues to use the locally shipped Inter family.

Upstream: https://github.com/adobe-fonts/source-serif
Specimen: https://adobe-fonts.github.io/source-serif/
Web distribution: Google Fonts, Source Serif 4 v15, retrieved 2026-11-02.

The stylesheet pins the first twelve SHA-256 digits in every font URL.
When updating, preserve the upstream license, Unicode ranges and both axes;
update the CSS digests and this table together.
