Condizioni e limiti

  • Startup template warmup is now enabled; the November 2 complete HTTP harness disabled it.
  • Historical measurements were taken on another date; differences are observations, not a paired experiment isolating code changes.
  • Some pages now expose additional workflows and controls; response bytes are recorded because the generated HTML is not necessarily identical.
  • The previous four-worker run selected only four hot member pages; the current four-worker run executes the full workload.
  • Four-worker notifications already varied between about 272 and 617 requests/s in successful archived runs; the official reference alone cannot establish a proportional gain.
  • Generator, Hypnotoad and PostgreSQL share the local machine; no TLS, WAN, external services or browser rendering is measured.
  • Semantic inference is optional and disabled by the default empty model path; synthetic SQL vector fixtures in the diagnostic tier do not measure real model inference.
  • Operation diagnostics use varying fixtures and intentional exceptions and are not HTTP capacity comparisons.
